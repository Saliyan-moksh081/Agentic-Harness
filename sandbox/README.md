# Sample coding tasks

## Palindrome

Implement `is_palindrome(text)` in `src/palindrome.py`. Ignore letter case and spaces, return true for palindromes and false otherwise, and treat empty text as a palindrome.

## Slugify

Implement `slugify(text)` in `src/slug.py`. Convert text to lowercase, replace spaces with a single hyphen, remove punctuation, and trim leading or trailing hyphens.

Do not change files under `tests/`.
